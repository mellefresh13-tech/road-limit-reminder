# Road Limit Reminder

Android-приложение показывает ограничение скорости на текущем дорожном участке по GPS. Это не навигатор: маршруты от адреса до адреса, карта и поиск адресов не входят в приложение.

## Версия 0.5.0

- GPS foreground service запускается после нажатия кнопки.
- После получения двух последовательных точек GPS приложение отправляет короткий трек в **2ГИС Map Matching API**.
- В ответе используются дорожные участки, сопоставленные 2ГИС, и ограничение скорости на текущем участке.
- Если на одном дорожном участке есть несколько ограничений, используется детализация `speed_limits` по расстоянию от начала участка.
- Первый запрос уходит после двух GPS-точек; далее запросы используют до десяти последних последовательных точек. После ответа текущие дорожные рёбра сопоставляются с новыми GPS-фиксациями локально, без повторного запроса на каждой секунде. Новый запрос отправляется, когда автомобиль выходит за геометрию участков, полученных от 2ГИС.
- Ответ 2ГИС не сохраняется на диск. Геометрия последнего восстановленного трека и скоростные интервалы удерживаются только в оперативной памяти активного сеанса и используются для локального сопоставления следующих GPS-фиксаций.
- При неоднозначном сопоставлении, отсутствии лимита, устаревшем GPS или ошибке API приложение скрывает лимит, а не подставляет предположительное значение.
- В уведомлении Android отображается текущий лимит.

## Настройка ключа 2ГИС

Для работы нужен доступ к **Navigation API → Map Matching API**.

1. Зарегистрируйтесь в [Менеджере платформы 2ГИС](https://platform.2gis.ru/).
2. Создайте демо-ключ или подключите подписку и включите в ключе сервис Map Matching API.
3. В GitHub откройте Settings → Secrets and variables → Actions.
4. Создайте repository secret с именем `DGIS_API_KEY` и вставьте API-ключ 2ГИС.
5. Запустите workflow **Android CI** или отправьте новый commit в ветку.

Если ключ отсутствует, APK всё равно собирается, но приложение покажет понятное сообщение о необходимости настройки `DGIS_API_KEY`.

**Важно о ключе:** API-ключ используется непосредственно Android-приложением и поэтому находится в собранном APK. GitHub Secret скрывает его от исходного кода репозитория, но не делает секретным после сборки. Используйте отдельный ключ только для Map Matching, задайте ограничение по HTTP User-Agent `RoadLimitReminder/0.5 (Android; com.domanovsky.roadlimit)`, установите лимиты и уведомления о расходе в кабинете 2ГИС. Не используйте ключ с доступом к другим API.

## Как работает обновление

1. После запуска сервис получает GPS-точки с интервалом около секунды.
2. После двух пригодных последовательных точек отправляется первый запрос Map Matching.
3. После ответа геометрия маршрута используется локально на каждой новой GPS-фиксации. Пока машина остаётся на полученных рёбрах, повторный API-запрос не нужен.
4. Когда GPS выходит за известные рёбра или появляется неоднозначность, приложение скрывает неподтверждённый лимит и отправляет новый трек из последних GPS-точек.
5. После сетевой ошибки выполняется повтор с экспоненциальной задержкой.

Точки GPS отправляются в 2ГИС: широта, долгота, время фиксации, скорость и направление движения (если Android их предоставил). Локально история поездки не записывается.

## Ограничения и безопасность

- Покрытие и полнота ограничений зависят от дорожного графа и данных карты 2ГИС. До подтверждения реальной работы на маршрутах в Беларуси нельзя считать покрытие Бреста и других городов гарантированным.
- Map Matching API предназначен для последовательного GPS-трека по дорогам общего пользования; документация рекомендует не менее 10 точек, хотя минимально допустимы две.
- Публичный API 2ГИС тарифицирует каждый успешный запрос Map Matching. Бесплатный демо-ключ ограничен 1 000 запросов на сервис и действует один месяц. Перед постоянным использованием проверьте цену и лимиты в Менеджере платформы.
- Ответы 2ГИС не сохраняются на постоянное хранилище; маршрут и скоростные интервалы используются только в оперативной памяти активного сеанса.
- Потеря сети или отказ API означает, что новый лимит получить нельзя. Приложение не подставляет старые данные из OSM и не выдаёт предположение за подтверждённое ограничение.
- Приложение не заменяет дорожные знаки и ПДД. Всегда ориентируйтесь на реальные знаки, особенно если информация отсутствует или кажется сомнительной.

## Проверка

1. Создайте ключ 2ГИС с включённым Map Matching API и сохраните его в GitHub Secrets как `DGIS_API_KEY`.
2. Установите debug APK из GitHub Actions artifact **Android Test APK**.
3. Разрешите точную геолокацию и уведомления.
4. Запустите отслеживание на дороге общего пользования, дождитесь GPS и ответа 2ГИС.
5. Проверьте смену лимита при переходе на другой дорожный сегмент и отсутствие значения при неоднозначном GPS.
6. Проверяйте только с пассажиром или на безопасно остановленном автомобиле. Не взаимодействуйте с телефоном за рулём.

## Атрибуция и конфиденциальность

- Картографический источник ограничений: 2ГИС.
- При работе отправляются GPS-точки в 2ГИС для сопоставления дорожного участка и получения его скоростного ограничения.
- Приложение не имеет собственного backend и не отправляет историю поездок разработчику.
- На экране приложения отображается атрибуция 2ГИС со ссылкой на [dev.2gis.ru](https://dev.2gis.ru/).

## Сборка

Android Studio / Gradle, JDK 17, Android SDK 36. GitHub Actions запускает unit-тесты и собирает debug APK.
