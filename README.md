# Road Limit Reminder

Android-приложение показывает ограничение скорости на текущей дороге по GPS. Это не навигатор: маршруты, карта и поиск адресов не входят в приложение.

## Версия 0.6.0

- GPS foreground service запускается после нажатия кнопки.
- После определения страны выбирается локальная SQLite-база дорожных ограничений.
- База содержит дорожные сегменты, bounding boxes, геометрию в формате Google encoded polyline и значения скорости.
- GPS-координаты сопоставляются с реальной геометрией ближайших дорожных сегментов прямо на устройстве.
- Ограничение выбирается по минимальному расстоянию до сегмента; соседние дороги с различающимися лимитами не объединяются в произвольное значение.
- Координаты пользователя не отправляются в Overpass или платный картографический API.
- Базы хранятся во внутреннем каталоге приложения и доступны офлайн после первой загрузки.
- При наличии сохранённой базы она открывается до попытки обновления.
- Проверка обновления выполняется не чаще одного раза в 30 дней.
- Если у дороги в базе нет maxspeed, приложение не подставляет предполагаемый лимит.

## Источник данных

Используется открытая дорожная база на основе OpenStreetMap, подготовленная проектом [HvdWolf / SpeedAlert_Databases](https://github.com/hvdwolf/SpeedAlert_Databases).

- Исходные дорожные данные: OpenStreetMap, лицензия ODbL.
- Подготовленные SQLite-базы: CC BY 4.0.
- Формат базы и алгоритм локального поиска описаны в [документации SpeedAlert](https://github.com/hvdwolf/SpeedAlert/blob/main/LocalDatabases.md).
- Европейский набор обновляется отдельными релизами GitHub. В релизе europe-202610 от 29 октября 2026 года опубликована база Беларуси by.sqlite.7z, архив около 4,6 МБ.

Первый запуск в стране, для которой база ещё не скачана, требует подключения к интернету для загрузки архива и распаковки. После этого проверка ограничения выполняется локально и работает без интернета. Данные дорожной базы не входят в APK.

## Как работает обновление

1. После разрешения точной геолокации приложение получает координаты GPS.
2. Android Geocoder определяет код страны; он используется только для выбора соответствующей базы.
3. Если база уже сохранена, приложение открывает её локально.
4. Если базы нет или пришло время обновления, архив скачивается из публичных GitHub Releases, проверяется и устанавливается во внутренний каталог приложения.
5. На каждой GPS-фиксации приложение выбирает записи по bounding boxes, затем измеряет расстояние до геометрии дороги.
6. При неоднозначном выборе дорог с разными лимитами значение не показывается.

Никаких API-ключей и платных сервисов не требуется. Публичный Overpass API не используется.

## Ограничения и безопасность

- Наличие базы страны зависит от того, опубликована ли она в проекте SpeedAlert_Databases.
- Полнота ограничений зависит от заполнения maxspeed в OpenStreetMap. Отсутствие тега не означает отсутствия ограничения на дороге.
- Локальная база содержит данные на момент её последней публикации. Новые или временные знаки могут отсутствовать до обновления базы.
- Если геометрия или GPS не позволяют уверенно выбрать дорогу, приложение скрывает лимит вместо подстановки значения с соседней дороги.
- Приложение не заменяет реальные дорожные знаки и ПДД.
- Reverse geocoding выполняется системным Android Geocoder. Сторонний сервер Road Limit Reminder не получает историю поездок.

## Проверка

1. Установить debug APK из GitHub Actions artifact **Android Test APK**.
2. Разрешить точную геолокацию и уведомления.
3. Нажать «Начать отслеживание».
4. При первом запуске в Беларуси дождаться загрузки базы by.sqlite.7z.
5. Проверить отображение ограничения на дороге с заполненным maxspeed.
6. Отключить интернет и повторить запуск: установленная база должна продолжить работать.
7. Проверить дорогу без maxspeed и параллельные дороги с разными значениями: приложение не должно придумывать лимит или выбирать соседнюю дорогу.

Полевые проверки выполняйте с пассажиром или на безопасно остановленном автомобиле. Не взаимодействуйте с телефоном за рулём.
