# Источники данных

## OpenStreetMap

OSM — основной и единственный внешний источник дорожной геометрии и внесённых сообществом дорожных ограничений.

Загружаются:
- автомобильные ways и их геометрия;
- `maxspeed`, `maxspeed:motorcar`, `maxspeed:motor_vehicle`;
- `maxspeed:forward`, `maxspeed:backward`;
- `traffic_sign:forward`, `traffic_sign:backward`;
- conditional, variable и lane tags для безопасного отказа от неоднозначного значения;
- физические nodes с `traffic_sign` и/или `maxspeed`;
- административная страна и place-контекст.

Ссылки:
- https://www.openstreetmap.org/copyright
- https://wiki.openstreetmap.org/wiki/Key:maxspeed
- https://wiki.openstreetmap.org/wiki/Key:traffic_sign
- https://wiki.openstreetmap.org/wiki/Key:maxspeed:conditional
- https://download.geofabrik.de/europe/belarus.html — выгрузка той же базы OSM, не независимый источник.

Физический node знака не гарантирует разметку всего участка его действия. Приложение не назначает знак ближайшей дороге без проверки связи/направления и не продлевает действие знака произвольным расстоянием. Приоритетным является maxspeed на соответствующем дорожном сегменте. Отдельные sign nodes сохраняются в кэше как дополнительные OSM-данные, но не используются для выдумывания продолжительности зоны.

## Беларусь: ПДД

Базовые правила для легкового автомобиля берутся из главы 11 ПДД РБ:
- п.88: 60 км/ч в населённых пунктах; 20 км/ч в жилых/пешеходных зонах и на прилегающих территориях;
- п.89.1: вне населённых пунктов до 120 км/ч на автомагистралях и дорогах для автомобилей, до 90 км/ч на остальных дорогах.

Источники:
- https://propdd.by/theory/glava-11
- https://gibdd.by/izmenenia_pdd_2025.html
- https://wiki.openstreetmap.org/wiki/Key:maxspeed

В приложении контекст страны и населённого пункта определяется по OSM area. Отсутствие полигона населённого пункта не доказывает нахождение вне населённого пункта; это ограничение источника.

## Overpass

Endpoints:
- https://overpass-api.de/api/interpreter
- https://overpass.kumi.systems/api/interpreter

Оба обслуживают одну базу OSM; второй endpoint — резерв доступа, не независимое подтверждение. Запрос выполняется при старте, выходе за радиус локального кэша или истечении шестичасового интервала. При ошибке сети кэш используется в пределах своего региона и возраста.

## Ограничения источников

- OSM неполон и может быть устаревшим.
- Локальный знак, отсутствующий в OSM, приложению неизвестен.
- Знак node сам по себе не задаёт автоматически длину зоны действия.
- Conditional, variable и lane-specific ограничения не вычисляются.
- Для directional limits требуется надёжно определённое направление движения.
- Нет найденного общедоступного полного real-time API дорожных знаков Беларуси.
- Данные о камерах фотофиксации не покрывают всю дорожную сеть и не заменяют дорожные ограничения.

## Лицензия

Данные OSM распространяются под ODbL. При распространении производных данных необходимо соблюдать условия лицензии и указывать OpenStreetMap contributors.
