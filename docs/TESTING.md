# Проверка Road Limit Reminder 0.6.0

## Подготовка

1. Установить debug APK из GitHub Actions artifact **Android Test APK**.
2. Включить интернет и GPS/геолокацию.
3. Разрешить точную геолокацию и уведомления.

## Сценарии

1. **Старт:** нажать «Начать отслеживание». Foreground service и ожидание GPS должны запуститься.
2. **Страна:** приложение определяет код страны системным Android Geocoder.
3. **Первая загрузка:** в Беларуси скачивается архив by.sqlite.7z, база распаковывается и открывается без падения приложения.
4. **Локальная база:** после установки базы выключить интернет и продолжить поездку. Lookup должен работать без сетевого доступа.
5. **Явное ограничение:** на дороге с maxspeed отображается значение из SQLite.
6. **Отсутствующий maxspeed:** приложение не подставляет базовый лимит по типу дороги, а сообщает, что ограничение в OSM не указано.
7. **Параллельные дороги:** если ближайшие сегменты с разными лимитами сопоставляются неоднозначно, значение скрывается.
8. **GPS-точность:** при точности хуже допустимой значение не должно отображаться как достоверное.
9. **Обновление базы:** при активном GPS-отслеживании после истечения 24 часов приложение автоматически загружает новую версию. Если загрузка не удалась, старая база остаётся доступной.
10. **Повреждённый архив:** база не должна заменяться файлом, не прошедшим проверку SQLite-схемы.
11. **Остановка:** остановить отслеживание через экран или уведомление; GPS и foreground notification должны завершиться.
12. **Атрибуция:** на экране присутствуют OpenStreetMap contributors и HvdWolf / SpeedAlert_Databases.

Проверяйте только с пассажиром или на безопасно остановленном автомобиле. Не взаимодействуйте с телефоном за рулём.
