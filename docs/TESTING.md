# Ручная проверка версии 0.4.0

## Подготовка
- Включить GPS/геолокацию и интернет.
- Установить debug APK из GitHub Actions artifact **Android Test APK**.
- Разрешить точную геолокацию и уведомления.

## Сценарии
1. **Старт:** запустить отслеживание; появляется постоянное уведомление и статус ожидания GPS.
2. **OSM:** дождаться загрузки дорог, country/place context и sign nodes.
3. **Явный лимит:** на сегменте с числовым maxspeed показывается значение OSM.
4. **Направленный лимит:** для way с maxspeed:forward/backward проверить движение в обоих направлениях; должен применяться соответствующий тег.
5. **Неопределённое направление:** при низкой скорости directional limit не должен превращаться в произвольное число.
6. **Соседняя/встречная дорога:** убедиться, что nearby way или противоположное направление не подменяют текущий лимит.
7. **Перекрёсток/развязка:** при равных кандидатах с разными ограничениями показывается неопределённость, а не случайное значение.
8. **Conditional/variable/lanes:** значение не вычисляется и не подменяется общим maxspeed.
9. **Базовые правила BY:** проверить 60/90/120/20 только при наличии требуемого OSM country/place context.
10. **Room cache:** загрузить регион, полностью закрыть приложение и запустить снова в той же области. Кэш должен быть доступен до сетевого обновления.
11. **Офлайн в кэшированной области:** после успешной загрузки отключить сеть и перезапустить отслеживание в пределах 650 м от центра сохранённого региона. Должны использоваться сохранённые данные с пометкой об отсутствии сети.
12. **Вне кэша без сети:** не показывать старый регион как достоверное покрытие новой дороги.
13. **Обновление:** после 6 часов или выхода за область кэша выполняется сетевое обновление; при ошибке повтор не чаще чем через 10 минут.
14. **Потеря GPS:** устаревший GPS fix не должен оставлять прежний лимит активным.
15. **Остановка:** остановить через экран или уведомление; GPS и постоянное уведомление должны завершиться.

Физический sign node сам по себе не подтверждает длину зоны действия. Для устойчивого лимита на участке проверьте наличие maxspeed на соответствующем way. Приложение не должно самостоятельно придумывать окончание зоны.

Проверяйте только с пассажиром или на безопасно остановленном автомобиле. Не взаимодействуйте с телефоном за рулём.
