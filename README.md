# Road Limit Reminder

Android-приложение, которое показывает ограничение скорости на текущем участке дороги по геопозиции автомобиля.

**Это не навигатор:** приложение не строит маршруты, не предлагает пункты назначения и не отображает карту.

## Текущий статус

Проект находится на этапе MVP foundation. В этой первой итерации заложены Android-проект, правила работы с источниками данных и базовый парсер значений `maxspeed`. GPS, сопоставление координат с дорожным сегментом и экран с реальным лимитом будут добавляться отдельными проверяемыми этапами.

## Принципы

- Бесплатные открытые данные и open-source зависимости.
- Основной источник дорожных ограничений — OpenStreetMap (OSM), тег `maxspeed`.
- Никаких платных картографических API и SDK.
- Не угадывать ограничение: если достоверного значения нет или дорожный сегмент определён неоднозначно, показывать «Нет данных».
- Не выдавать нормативное значение по умолчанию за явно установленный лимит конкретного участка.
- Не отправлять историю перемещений на собственный сервер и не собирать телеметрию.
- В интерфейсе — только текущая скорость/лимит и состояние данных; без карты.

## Данные и лицензии

OSM — открытые географические данные под лицензией ODbL. При распространении производных баз необходимо соблюдать условия ODbL и атрибуцию OpenStreetMap contributors. Публичный Overpass API — способ запросить те же данные OSM, а не независимый второй источник подтверждения.

Подробности: [Политика источников данных](docs/DATA_SOURCES.md).

## Разработка

- Android / Kotlin
- Gradle + Android Gradle Plugin
- Unit-тесты для разбора ограничений скорости

Откройте проект в Android Studio и запустите конфигурацию `app`. CI проверяет unit-тесты и собирает debug APK.

## План MVP

1. Базовая Android-структура и безопасная модель ограничения скорости.
2. GPS location foreground service с прозрачным уведомлением и управлением запуском.
3. Локальная дорожная база OSM для Беларуси и последующее расширение покрытия.
4. Map matching: выбор дороги по расстоянию, направлению движения и непрерывности предыдущего сегмента.
5. Экран с крупным значением лимита, происхождением данных и состоянием достоверности.
6. Обновление дорожной базы без частых запросов к публичным Overpass-инстансам.
7. Опциональный плавающий индикатор — отдельным этапом и только после согласования.

## Безопасность и точность

Это вспомогательный информационный инструмент, а не сертифицированный автомобильный спидометр или юридический источник. Дорожные данные OSM могут быть неполными или устаревшими. Водитель обязан ориентироваться на дорожные знаки и ПДД.
