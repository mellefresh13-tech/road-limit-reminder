# Источники данных

## OpenStreetMap

Основной источник — дорожные сегменты OpenStreetMap и их теги. Числовой maxspeed без единицы измерения по правилам OSM интерпретируется в км/ч; mph указывается явно.

Ссылки:
- https://www.openstreetmap.org/copyright
- https://wiki.openstreetmap.org/wiki/Key:maxspeed
- https://wiki.openstreetmap.org/wiki/Key:maxspeed:conditional

## Получение данных

Для тестовой версии используются публичные Overpass API endpoints:
- https://overpass-api.de/api/interpreter
- https://overpass.kumi.systems/api/interpreter

Оба endpoint предоставляют данные OSM и не являются независимыми источниками дорожных ограничений. Второй endpoint используется только как технический резерв при ошибке первого.

Запрос получает геометрию автомобильных дорог в радиусе около 1,1 км. Обновление запускается при старте, перемещении примерно на 300 м или по истечении двух минут, а не на каждом GPS fix. Публичные серверы не предоставляют гарантированную доступность; при ошибке приложение показывает состояние недоступности данных.

## Ограничения интерпретации

- Условные ограничения не вычисляются, поскольку условия могут зависеть от времени, дня, погоды и других параметров.
- Переменные знаки не отображаются как постоянный лимит.
- Разные ограничения по полосам не выбираются без достоверного определения полосы.
- Ограничения по направлению пока не интерпретируются.
- Значения вроде BY:urban не преобразуются в нормативные значения автоматически.
- Отсутствующий maxspeed не означает отсутствие юридического ограничения.

## Лицензия

OSM распространяется под ODbL. Соблюдать атрибуцию OpenStreetMap contributors и условия лицензии при распространении производных данных.
