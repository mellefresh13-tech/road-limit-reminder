# Архитектура Road Limit Reminder 0.5.0

## Поток данных

1. Пользователь нажимает «Начать отслеживание».
2. Android выдаёт разрешение точной геолокации (если оно ещё не предоставлено) и запускается location foreground service.
3. Сервис получает GPS-точки с периодом около секунды.
4. После двух пригодных последовательных точек формируется первый запрос в 2ГИС Map Matching API; каждый запрос содержит от двух до десяти последних точек.
5. 2ГИС возвращает восстановленный трек, дорожные рёбра и скоростные ограничения.
6. Геометрия рёбер и интервалы ограничений остаются только в оперативной памяти активного сеанса.
7. Каждая новая GPS-фиксация локально сопоставляется с полученными рёбрами. По геометрии определяется смещение от начала ребра; если API вернул `speed_limits`, ограничение берётся из соответствующего интервала `start_offset..end_offset`, а не из среднего значения.
8. Пока машина остаётся на одном из полученных рёбер, повторный запрос к API не выполняется. Когда GPS выходит за известную геометрию или сопоставление становится неоднозначным, неподтверждённый лимит скрывается и отправляется новый трек из последних GPS-точек.
9. На экран и в уведомление передаётся лимит либо объяснение, почему достоверное значение получить не удалось.

## 2ГИС Map Matching API

- Endpoint: `https://routing.api.2gis.com/map_matching/1.0.0`.
- Метод: POST, JSON body, API key в query parameter `key`.
- Передаются `lon`, `lat`, `utc`; `speed` и `azimuth` передаются, если GPS их предоставляет.
- `need_speed_limits=true` запрашивает данные об ограничениях скорости.
- `search_radius=40` задаёт радиус поиска дорожного графа (значение по умолчанию в 2ГИС).
- `bad_point_tolerance=high` позволяет сервису пропускать отдельные плохие GPS-фиксации, если маршрут всё ещё можно восстановить.
- Для первого результата достаточно двух последовательных точек; каждый запрос содержит от 2 до 10 последних GPS-точек. 2ГИС допускает минимум две и рекомендует не менее десяти точек. После ответа приложение локально использует геометрию полученного трека и не опрашивает API по периодическому таймеру.
- `speed_limits` содержит подробные интервалы ограничения вдоль ребра. Координаты и смещения из ответа не переводятся в локальные постоянные данные.

## Текущий лимит и устаревание

- Используется только ограничение, сопоставленное 2ГИС с текущей точкой GPS.
- Если на дорожном ребре несколько лимитов, выбирается интервал, содержащий смещение текущей точки.
- Если GPS-фиксация устарела, текущая точка слишком далеко от последнего сопоставления или прошло слишком много времени, значение скрывается.
- Если источники/данные API неоднозначны или лимит не указан, значение остаётся пустым.
- Ошибки сети обрабатываются повтором с экспоненциальной задержкой.

## Кэширование и лицензия

Ответы 2ГИС и дорожная геометрия не записываются в Room, SharedPreferences, файлы или иное постоянное хранилище. Геометрия текущего восстановленного трека остаётся только в оперативной памяти активного сеанса и используется для сопоставления следующих GPS-фиксаций. После остановки сервиса или потери актуального GPS она удаляется. Постоянный офлайн-кэш данных 2ГИС не реализован и не используется.

## Ключ API

Gradle получает `DGIS_API_KEY` из Gradle property или переменной окружения и записывает его в BuildConfig. GitHub Actions передаёт secret с этим именем. Важно: любой ключ, встроенный в Android APK, можно извлечь. Поэтому нужен отдельный API-ключ с доступом только к Map Matching API, ограничением по HTTP User-Agent и настроенными лимитами/уведомлениями в Менеджере платформы.

## Ограничения

- Map Matching не гарантирует покрытие каждого дорожного участка и каждого ограничения в Беларуси. Необходимы реальные полевые проверки на маршрутах.
- API тарифицирует каждый успешный запрос. Запросы выполняются при выходе за полученную геометрию, поэтому фактический расход зависит от протяжённости дорожных рёбер и маршрута, а не от фиксированного таймера.
- API-провайдер может отвечать медленно или быть недоступен. Сервис 2ГИС предоставляется «как есть», поэтому абсолютная мгновенная и непрерывная работа не гарантируется.
- Приложение не подменяет отсутствующее значение базовыми правилами Беларуси: без подтверждённого лимита показывает отсутствие значения.
