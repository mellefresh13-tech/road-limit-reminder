# Road Limit Reminder

Android-приложение показывает ограничение скорости на текущей дороге по GPS. Это не навигатор: маршруты, карта и поиск адресов не входят в продукт.

## Версия 0.4.0

- GPS location foreground service, запуск/остановка и постоянное уведомление с числом лимита.
- Дорожные сегменты и их геометрия из OpenStreetMap.
- Загрузка OSM-узлов с `traffic_sign` / `maxspeed`, а также направленных тегов на дорожных участках.
- Map matching с оценкой расстояния, направления движения, предыдущего сегмента и неопределённости.
- Направленные `maxspeed:forward` / `maxspeed:backward` выбираются только при уверенно определённом направлении.
- Базовые правила Беларуси по главе 11 ПДД РБ: 60 км/ч в населённых пунктах, 120 км/ч на автомагистралях/дорогах для автомобилей вне населённых пунктов, 90 км/ч на остальных дорогах вне населённых пунктов, 20 км/ч на living_street.
- Room-кэш дорожных данных: повторное использование в пределах загруженной области, сохранение между перезапусками и доступность последнего набора при временном отсутствии сети.
- Обновление данных при выходе из области кэша или по шестичасовому интервалу; при сетевой ошибке повтор через 10 минут.
- Unit-тесты парсера, сериализации кэша, resolver и map matching.

## Важные ограничения

- Основной источник дорожной сети и знаков — OpenStreetMap. Данные вносятся сообществом, могут быть неполными, ошибочными или устаревшими.
- Отдельный физический узел знака не всегда описывает весь участок его действия. Приложение не продлевает действие знака по догадке: для устойчивого применения ограничения OSM должен содержать соответствующий `maxspeed` на затронутых дорожных сегментах.
- Условные, переменные и полосные ограничения не вычисляются. Направленные ограничения применяются только при достоверном определении направления движения.
- Для знаков с неуказанным значением `maxspeed` приложение не придумывает числовое ограничение.
- Базовые правила Беларуси зависят от корректности административных и населённых полигонов OSM. Отсутствие полигона не доказывает, что водитель находится вне населённого пункта.
- Локальные и временные знаки, не внесённые в OSM, приложению неизвестны. Камера и распознавание знаков не используются.
- Два Overpass endpoint — технический резерв доступа к одной базе OSM, а не два независимых источника.
- Кэш хранит один последний загруженный регион; при поездке далеко от него приложение загрузит новый регион. При отсутствии сети данные вне сохранённой области недоступны.
- Приложение не заменяет дорожные знаки и ПДД. Проверяйте показания по реальным знакам.

## Проверка

1. Установите debug APK из GitHub Actions artifact **Android Test APK**.
2. Разрешите точную геолокацию и уведомления.
3. Запустите отслеживание и дождитесь GPS/OSM.
4. Проверьте направленный лимит на тестовых сегментах и отсутствие значения при неоднозначном map matching.
5. Перезапустите приложение в пределах ранее загруженной области без сети: должен использоваться сохранённый кэш.
6. При проверке на дороге не взаимодействуйте с телефоном за рулём; безопаснее проводить тест с пассажиром.

## Данные и приватность

- Геоданные: OpenStreetMap, лицензия ODbL.
- Нормативные значения Беларуси: глава 11 ПДД РБ.
- Координаты текущего местоположения отправляются на публичный Overpass endpoint для получения окружающих данных.
- Приложение не имеет собственного backend, не отправляет историю поездок разработчику и не содержит аналитики/телеметрии.
- Кэш дорожных данных хранится локально в базе Room на устройстве.

## Сборка

Android Studio / Gradle, JDK 17, Android SDK 36. GitHub Actions запускает unit-тесты и собирает debug APK.
