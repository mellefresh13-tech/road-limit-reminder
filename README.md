# Road Limit Reminder

Android-приложение показывает ограничение скорости на текущей дороге по GPS.

**Это не навигатор:** приложение не строит маршруты, не ищет адреса и не отображает карту.

## Тестовая версия 0.3.0

- запуск и остановка GPS-отслеживания;
- Android location foreground service с постоянным уведомлением;
- динамический значок уведомления с числом текущего ограничения (например, 60) и заголовок уведомления в формате «60 км/ч»;
- единицы км/ч на главном экране показаны в виде дроби: км над чертой, ч под чертой;
- загрузка дорожной геометрии, тегов OSM, границы страны и полигонов населённых пунктов;
- базовые ограничения Беларуси по главе 11 ПДД РБ: 60 км/ч в населённых пунктах, 120 км/ч на автомагистралях/дорогах для автомобилей вне населённых пунктов, 90 км/ч на остальных дорогах вне населённых пунктов, 20 км/ч на living_street;
- явные числовые ограничения OSM имеют приоритет над значениями по умолчанию;
- резервный публичный Overpass endpoint;
- безопасное состояние «Нет данных» для отсутствующих/неоднозначных данных, условных, переменных, полосных и направленных ограничений;
- unit-тесты парсера, OSM-контекста, resolver и map matching.

## Ограничения тестовой версии

- Для получения дорожных данных нужен интернет.
- Данные загружаются вокруг текущего GPS-положения и кэшируются только в памяти процесса; офлайн-режима пока нет.
- Публичные Overpass-серверы могут быть перегружены или временно недоступны.
- Автоматические правила Беларуси зависят от полноты административных и населённых полигонов в OSM. Если контекст страны не определён, базовый лимит не угадывается.
- Локальные дорожные знаки могут изменять базовые ограничения ПДД; приложение пока не распознаёт все такие изменения.
- Условные ограничения, переменные знаки, разные лимиты по полосам и направлению пока не отображаются как числовой лимит.
- Map matching — MVP, не гарантия правильного выбора дороги на сложных развязках, параллельных проездах или при плохом GPS.
- Приложение не заменяет дорожные знаки и ПДД.

## Установка и проверка

1. Установите debug APK из GitHub Actions artifact **Android Test APK**.
2. Разрешите точную геолокацию и уведомления.
3. Нажмите «Начать отслеживание».
4. Дождитесь GPS и загрузки дорожных данных.
5. Сверяйте показания с реальными дорожными знаками; не используйте приложение как единственный источник ограничения.

## Данные и приватность

- Дорожные данные: OpenStreetMap, лицензия ODbL.
- Нормативные значения Беларуси: глава 11 ПДД РБ.
- Запросы отправляются на публичные Overpass endpoints. Координаты текущего местоположения включаются в запрос и передаются выбранному серверу.
- Приложение не имеет собственного backend, не отправляет историю поездок на сервер разработчика и не содержит аналитики/телеметрии.
- Сетевой запрос выполняется при старте, после перемещения примерно на 300 м или по истечении двух минут, а не на каждом GPS fix.

## Сборка

Android Studio / Gradle, JDK 17, Android SDK 36. GitHub Actions выполняет unit-тесты и собирает debug APK.
