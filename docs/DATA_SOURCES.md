# Политика источников дорожных ограничений

## Основной источник: OpenStreetMap

Для MVP используется открытая база OpenStreetMap (ODbL). Ключевое поле — `maxspeed` на дорожном сегменте. В дальнейшем учитываются связанные теги, в том числе:

- `maxspeed:conditional` — ограничения, действующие при заданных условиях;
- `source:maxspeed` и `maxspeed:type` — контекст происхождения/типа ограничения;
- `zone:maxspeed`, `traffic_sign`, `highway`, `junction`, `motorroad` — дополнительные признаки дорожного контекста;
- `maxspeed:advisory` — рекомендательная, а не обязательная скорость; не должна отображаться как юридический лимит.

Парсер должен различать числовые значения, единицы измерения, специальные значения (`signals`, `none`, `walk`) и условные ограничения. Неизвестное значение не преобразуется в число по догадке.

## Дополнительные источники и независимость

Публичный Overpass API и выгрузки Geofabrik — разные способы получения данных OSM, но не независимые источники истины. Их нельзя считать двумя подтверждениями одного ограничения.

Дополнительный национальный источник подключается только если одновременно выполнены условия:

1. Набор действительно открыт и бесплатен для использования в приложении.
2. Лицензия и требования атрибуции документированы.
3. Данные имеют геопривязку, дату актуальности и понятную методику.
4. Можно сопоставить его дорожный участок с сегментом OSM.
5. Конфликты разрешаются явным правилом приоритета; значения не усредняются.

До проверки конкретного набора данных он не считается подключённым источником.

## Правило отображения

- Явный и однозначно сопоставленный `maxspeed` — можно показывать как значение из OSM.
- Условный лимит — только после реализации и проверки соответствующего условия; иначе «Нет данных».
- `none`, `signals`, `walk` и неизвестные символические значения — не превращать в произвольное число.
- Отсутствующий `maxspeed` — не означает, что ограничение отсутствует.
- Конфликт источников или неоднозначное сопоставление дороги — «Нет данных» до разрешения конфликта.
- Общие ограничения из ПДД могут рассматриваться отдельно как «расчётное значение», только если надёжно известны страна, категория дороги, тип ТС и все условия. Они не должны маскироваться под дорожный знак или явный OSM-тег.

## Сетевые ограничения

Публичные Overpass-инстансы не являются гарантированным production API и имеют ограничения нагрузки. Нельзя выполнять запрос на каждом GPS-обновлении. Предпочтительная схема — локальная дорожная база с редкими пакетными обновлениями; сетевой запрос может быть резервным механизмом с кэшированием и уважением лимитов сервиса.
