# Источники данных Road Limit Reminder

## Основной источник: 2ГИС

Приложение использует **Navigation API → Map Matching API**.

- Документация: https://docs.2gis.com/api/navigation/map-matching/overview
- Справочник: https://docs.2gis.com/api/navigation/map-matching/reference/map_matching
- Релизы: https://docs.2gis.com/api/navigation/map-matching/releases
- Менеджер платформы: https://platform.2gis.ru/
- Ключи API: https://docs.2gis.com/platform-manager/subscription/keys
- Управление ключами и ограничениями: https://docs.2gis.com/platform-manager/subscription/managing-keys
- Тарифы и лимиты: https://docs.2gis.com/platform-manager/subscription/pricing
- Оферта WebAPI: https://law.2gis.ru/offer-license-agreement-webapi

Запрос содержит последовательные GPS-точки одного устройства и одной поездки. Документация допускает от 2 до 1000 точек, рекомендуя не менее 10; интервал между фиксациями — 1–10 секунд. В ответе возвращается восстановленный автомобильный трек, дорожные рёбра, их геометрия и ограничения скорости. При нескольких ограничениях на одном ребре используется массив `speed_limits`, содержащий интервалы смещений.

## Режим обновления

- Первый запрос выполняется после двух пригодных точек, чтобы сократить время до первого результата.
- Далее запрос отправляется после накопления десяти точек.
- Обновление необходимо для определения нового ребра и нового ограничения.
- Успешные запросы тарифицируются поштучно. В актуальной документации демо-ключ действует один месяц; Map Matching API имеет лимит 1 000 демо-запросов. В подписке 10 000 единиц Map Matching API указаны по цене 6 700 ₽; фактическую цену, доступность и условия следует перепроверять в Менеджере платформы перед включением постоянного использования.

## Ограничения ключа

- Для прямого HTTP API нужен отдельный ключ без режима mobile SDK.
- Включать в ключе следует только Map Matching API.
- Рекомендуется ограничить ключ по User-Agent: `RoadLimitReminder/0.5 (Android; com.domanovsky.roadlimit)`.
- В кабинете 2ГИС можно ограничивать использование сервиса и задавать уведомление, остановку или блокировку при достижении лимита.
- Ключ, встроенный в APK, технически можно извлечь. GitHub Secret не делает ключ недоступным из уже собранного приложения.

## Кэширование и персональные данные

Приложение не сохраняет ответы 2ГИС на постоянное хранилище. API получает координаты, Unix-время, скорость и направление движения, если они доступны. История поездок не сохраняется и собственный сервер разработчика не используется.

## Что не используется

- HERE — не подключён.
- Публичный Overpass API — не вызывается приложением.
- OSM — не используется в качестве онлайн-резерва в этой версии.
- Локальные предположительные правила ПДД не подменяют отсутствующий ответ 2ГИС.
