# Архитектура Road Limit Reminder

## Поток данных

1. Android Location API передаёт координаты, скорость, bearing, точность и время GPS fix.
2. Location foreground service проверяет локальный Room-кэш.
3. Если точка находится в радиусе 650 м от центра последней загрузки и кэш не старше 24 часов, данные доступны сразу, в том числе после перезапуска приложения.
4. Overpass загружает дорожные ways, физические sign nodes с тегами `traffic_sign` / `maxspeed`, страну и содержащие точку полигоны населённых пунктов.
5. Успешный ответ сериализуется и сохраняется в Room. Сеть обновляется при выходе из кэшированной области или через 6 часов; после ошибки повторяется не чаще чем через 10 минут.
6. RoadMatcher оценивает расстояние до сегмента, heading, one-way и непрерывность предыдущего сегмента. При неопределённости ограничение скрывается.
7. Resolver учитывает направление для `maxspeed:forward/backward`, явные значения, символические значения OSM и базовые правила Беларуси.
8. UI и уведомление получают подтверждённое значение либо причину отсутствия достоверных данных.

## OSM данные

- Ways: highway, геометрия, maxspeed, maxspeed:motorcar, maxspeed:motor_vehicle, maxspeed:forward/backward, traffic_sign:forward/backward, conditional/variable/lane tags.
- Nodes: физические знаки с traffic_sign и/или maxspeed, координаты и direction tags.
- Areas: административная страна и place-полигоны для контекста ПДД.

Физический узел знака и участок действия — разные сущности. Сам факт наличия node рядом не доказывает, что знак относится к текущей дороге или направлению. Приложение не переносит лимит узла на произвольные сегменты. Для применения ограничения на протяжении участка OSM должен содержать maxspeed на затронутых ways или корректные направленные теги.

## Map matching

- Расстояние от GPS fix до каждого сегмента.
- Согласованность bearing и геометрии сегмента.
- Учёт oneway=yes / -1.
- Стабильность предыдущего way ID.
- Проверка неоднозначных кандидатов с разными ограничениями.
- Направление FORWARD/BACKWARD определяется только при скорости от 3 м/с; иначе directional limit не применяется.

## Resolver

1. Conditional, variable и lane-specific значения не сводятся к одному числу.
2. Направленные maxspeed выбираются по установленному направлению; если оно неизвестно, результат unavailable.
3. Явный числовой maxspeed имеет приоритет.
4. BY symbolic values и базовые правила Беларуси применяются при наличии требуемого контекста.
5. Конфликт/неполные данные не заменяются догадкой.

## Локальный кэш

Room хранит последний регион OSM: центр загрузки, timestamp и JSON payload roads/signs/areas. Кэш ограничен одним регионом, радиусом повторного использования 650 м и возрастом 24 часа. Это локальная копия данных OSM, а не независимый источник. Если пользователь уезжает за пределы региона без сети, приложение не экстраполирует дорожную сеть.

## Ограничения

Не реализованы вычисление полных зон действия знаков по цепочке перекрёстков, автоматическая интерпретация conditional/variable/lane restrictions и полное покрытие всех локальных знаков. Для таких функций необходимы более полные OSM-данные по affected road sections и отдельная проверенная state-machine по ПДД РБ.
