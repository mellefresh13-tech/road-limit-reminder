# Road Limit Reminder

Android-приложение показывает ограничение скорости на текущей дороге по GPS.

**Это не навигатор:** приложение не строит маршруты, не ищет адреса и не отображает карту.

## Тестовая версия 0.2.0

- запуск и остановка GPS-отслеживания;
- Android location foreground service с постоянным уведомлением;
- загрузка геометрии дорог и OSM-тегов поблизости через публичный Overpass API;
- сопоставление GPS-положения с дорожными сегментами по расстоянию и направлению движения;
- отображение явного числового ограничения из OSM;
- безопасное состояние «Нет данных» для отсутствующих, условных, переменных, полосных и неоднозначных ограничений;
- резервный публичный Overpass endpoint;
- unit-тесты парсера, JSON-импорта, resolver и базового map matching.

## Ограничения тестовой версии

- Для получения дорожных данных нужен интернет.
- Данные загружаются вокруг текущего GPS-положения и кэшируются только в памяти процесса; офлайн-режима пока нет.
- Публичные Overpass-серверы могут быть перегружены или временно недоступны.
- Показываются только явно заданные числовые ограничения. Общие ограничения из ПДД и неявные значения вроде BY:urban пока не вычисляются.
- Условные ограничения, переменные знаки, разные лимиты по полосам и направлению пока не отображаются как числовой лимит.
- Map matching — первая практическая реализация, а не гарантия правильного определения дороги на сложных развязках, параллельных проездах или при плохом GPS.
- Приложение не заменяет дорожные знаки и ПДД.

## Установка и проверка

1. Установите debug APK из GitHub Actions artifact **Android Test APK**.
2. Разрешите точную геолокацию и уведомления.
3. Нажмите «Начать отслеживание».
4. Дождитесь GPS и загрузки OSM.
5. Проверьте отображение на дороге с известным и явно размеченным ограничением.
6. Сверяйте показания с реальными дорожными знаками; не используйте приложение как единственный источник ограничения.

## Данные и приватность

- Дорожные данные: OpenStreetMap, лицензия ODbL.
- Запросы отправляются на публичные Overpass endpoints. Координаты текущего местоположения включаются в запрос для получения ближайших дорог и передаются выбранному Overpass-серверу.
- Приложение не имеет собственного backend, не отправляет историю поездок на сервер разработчика и не содержит аналитики/телеметрии.
- Сетевой запрос выполняется при старте, после перемещения примерно на 300 м или по истечении двух минут, а не на каждом GPS-обновлении.

## Сборка

Android Studio / Gradle, JDK 17, Android SDK 36. GitHub Actions выполняет unit-тесты и собирает debug APK.
