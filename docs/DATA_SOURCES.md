# Источники данных

## 1. Дорожная сеть и дорожные знаки: OpenStreetMap

Основной географический источник — OpenStreetMap (OSM), включая:
- геометрию автомобильных дорог;
- теги highway, motorroad, maxspeed и связанные ограничения;
- административные границы стран;
- полигоны населённых пунктов с тегами place.

Числовой maxspeed без единицы измерения интерпретируется как км/ч по правилам OSM. Явное числовое ограничение на дороге имеет приоритет над нормативным значением по умолчанию.

Ссылки:
- https://www.openstreetmap.org/copyright
- https://wiki.openstreetmap.org/wiki/Key:maxspeed
- https://wiki.openstreetmap.org/wiki/Key:maxspeed:conditional
- https://download.geofabrik.de/europe/belarus.html — бесплатный PBF-экспорт всей Беларуси (ODbL). Это выгрузка той же базы OSM, а не независимый источник ограничений.

## 2. Беларусь: нормативные ограничения по ПДД

Для Беларуси добавлен отдельный слой правил на основе главы 11 ПДД РБ:
- пункт 88: в населённых пунктах — 60 км/ч; в жилых/пешеходных зонах и на прилегающих территориях — 20 км/ч;
- пункт 89.1: для легковых автомобилей вне населённых пунктов — до 120 км/ч на автомагистралях и дорогах для автомобилей, до 90 км/ч на остальных дорогах.

Источники текста действующей редакции:
- https://propdd.by/theory/glava-11 — глава 11 ПДД РБ; текст приведён по Указу Президента № 551 и последующим изменениям, официальный текст публикуется на pravo.by.
- https://gibdd.by/izmenenia_pdd_2025.html — разъяснение изменений по Указу № 295 от 04.08.2025.
- https://wiki.openstreetmap.org/wiki/Key:maxspeed — документированные значения BY:urban, BY:rural, BY:motorway, BY:living_street. При расхождении со старой таблицей OSM используются актуальные значения ПДД РБ.

Приложение получает через Overpass не только дорожные сегменты, но и административную область страны и содержащие GPS-точку OSM-полигоны населённых пунктов. Для Беларуси:
- внутри найденного полигона населённого пункта применяется 60 км/ч;
- вне найденных полигонов — 120 км/ч для motorway, motorway_link и motorroad=yes, 90 км/ч для остальных загруженных автомобильных дорог;
- living_street — 20 км/ч;
- значения BY:urban, BY:rural, BY:motorway, BY:living_street в maxspeed, source:maxspeed или zone:traffic также распознаются.

Если Overpass не вернул область страны, национальные правила Беларуси не применяются. Классификация населённого пункта зависит от полноты OSM-полигонов: отсутствие полигона не доказывает, что водитель находится вне населённого пункта. На практике это необходимо отдельно проверить на поездках по Беларуси. Дорожные знаки могут менять базовые ограничения; приложение не распознаёт все временные и локальные знаки.

## 3. Официальные данные фотофиксации

Сайт СЗАО «Безопасные дороги Беларуси» сообщает, что сведения об ограничениях скорости и местах установки датчиков можно получить на странице фотофиксации:
- https://www.speed-control.by/faq-ru.html

На момент разработки не найден общедоступный машиночитаемый API или лицензированный полный набор дорожных сегментов с лимитами. Поэтому сайт не подключён как автоматический источник. Данные о камерах сами по себе не покрывают всю дорожную сеть и не могут заменить ограничения по ПДД и дорожным знакам.

## Получение данных в приложении

Используются публичные Overpass API endpoints:
- https://overpass-api.de/api/interpreter
- https://overpass.kumi.systems/api/interpreter

Оба endpoint обслуживают одну базу OpenStreetMap. Второй является только техническим резервом первого, а не независимым подтверждением данных.

Запрос получает геометрию автомобильных дорог в радиусе около 1,1 км, а также административный и населённый контекст текущей GPS-точки. Обновление запускается при старте, перемещении примерно на 300 м или по истечении двух минут. Координаты устройства передаются выбранному публичному Overpass-серверу.

## Ограничения интерпретации

- Условные ограничения не вычисляются, поскольку условия могут зависеть от времени, дня, погоды и других параметров.
- Переменные знаки не отображаются как постоянный лимит.
- Разные ограничения по полосам не выбираются без достоверного определения полосы.
- Ограничения по направлению пока не интерпретируются.
- Значение по ПДД — базовое нормативное ограничение, а не гарантия отсутствия локального знака с другим значением.
- Данные OSM создаются сообществом и могут быть неполными или устаревшими.

## Лицензия

Данные OpenStreetMap распространяются под ODbL. При распространении производных данных необходимо соблюдать условия лицензии и указывать OpenStreetMap contributors.
