# Проверка Road Limit Reminder 0.5.0

## Подготовка

1. Создать в Менеджере платформы 2ГИС демо-ключ или подключить подписку.
2. Включить Map Matching API и ограничить ключ по User-Agent `RoadLimitReminder/0.5 (Android; com.domanovsky.roadlimit)`.
3. Сохранить ключ в GitHub Actions Secrets как `DGIS_API_KEY`.
4. Установить debug APK из GitHub Actions artifact **Android Test APK**.
5. Разрешить точную геолокацию и уведомления.

## Сценарии

1. **Первый запуск:** открыть приложение, нажать «Начать отслеживание», разрешить геолокацию. Foreground service и экран ожидания должны запуститься.
2. **Первое сопоставление:** после двух последовательных пригодных GPS-точек отправляется запрос 2ГИС; после получения ответа отображается текущее ограничение, если оно присутствует в ответе.
3. **Последовательность точек:** запросы содержат точки одного устройства и одной поездки, время между соседними точками не превышает 10 секунд.
4. **Ограничения по участкам:** если API возвращает несколько интервалов `speed_limits` на одном ребре, на текущей позиции применяется именно соответствующий интервал, а не усреднённое значение ребра.
5. **Следующее ребро:** при движении на другой дорожный сегмент обновление должно заменить предыдущее значение.
6. **Нет лимита в ответе:** показать отсутствие ограничения, а не придуманное число.
7. **Неоднозначный GPS:** при плохой точности, плохих точках или неуспешном map matching не показывать неподтверждённый лимит.
8. **Потеря сети:** показать ошибку и повторить запрос с экспоненциальной задержкой; не выдавать старое значение как актуальное после истечения времени/перемещения.
9. **Ошибка API key:** проверить понятное сообщение для HTTP 401/403; проверить, что без ключа приложение не отправляет пустой запрос.
10. **Превышение лимита:** проверить сообщение для HTTP 429 и убедиться, что запросы не повторяются в цикле без задержки.
11. **Остановка:** нажать кнопку остановки или соответствующее действие уведомления; GPS обновления и foreground notification должны завершиться.
12. **Атрибуция:** на экране должна быть видна подпись «2ГИС», открывающая https://dev.2gis.ru/.

## Важно

Map Matching API предназначен для последовательных точек GPS автомобиля на дорогах общего пользования. Проверять только с пассажиром или на безопасно остановленном автомобиле. Не взаимодействовать с телефоном за рулём.
