# Ручная проверка тестовой версии

## Подготовка

- Включить GPS/геолокацию на устройстве.
- Убедиться, что есть доступ в интернет.
- Установить debug APK из GitHub Actions.
- Разрешить приложению точную геолокацию и уведомления.

## Сценарии

1. **Старт:** нажать «Начать отслеживание». Должно появиться постоянное уведомление и статус ожидания GPS.
2. **Получение координат:** на открытом месте дождаться GPS fix. Статус должен смениться на загрузку OSM.
3. **Дорога с maxspeed:** на сегменте с явным числовым ограничением должен появиться лимит и название дороги (если оно есть в OSM).
4. **Нет maxspeed:** на дороге без явного числового тега должно отображаться «Нет данных», а не предполагаемое значение.
5. **Условное ограничение:** для сегмента с условным maxspeed приложение должно сообщить, что условное ограничение пока не поддерживается.
6. **Потеря GPS:** после потери или ухудшения GPS приложение не должно продолжать считать старое значение актуальным.
7. **Нет интернета:** приложение должно сообщить о невозможности загрузить дорожные данные; не должно показывать случайный лимит.
8. **Остановка:** нажать «Остановить отслеживание» в приложении или в уведомлении. GPS-отслеживание и постоянное уведомление должны завершиться.

Тестируйте только с пассажиром или на безопасно остановленном автомобиле. Не взаимодействуйте с телефоном во время управления автомобилем. Сверяйте все значения с дорожными знаками.
