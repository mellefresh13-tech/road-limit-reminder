# Архитектура Road Limit Reminder 0.6.0

## Поток данных

1. Пользователь нажимает «Начать отслеживание» и при необходимости разрешает точную геолокацию.
2. Location foreground service получает GPS-фиксации примерно раз в секунду.
3. Android Geocoder определяет код страны в фоновом потоке.
4. OpenSpeedDatabaseManager открывает сохранённую SQLite-базу страны из внутреннего каталога приложения. Если базы ещё нет, она скачивается из публичного GitHub Release.
5. Архив .sqlite.7z распаковывается во временный файл. Проверяется SQLite-схема speed_index и speed_data; только после проверки база устанавливается на место рабочей.
6. На каждой GPS-фиксации SQL-запрос выбирает потенциальные дорожные сегменты по bounding boxes с запасом на точность GPS.
7. Google encoded polylines декодируются; расстояние от позиции GPS до каждого сегмента вычисляется в метрах.
8. Выбирается ближайший сегмент. Если два близких сегмента имеют разные ограничения и сопоставление неоднозначно, приложение скрывает лимит.
9. В UI и уведомление передаётся значение из локальной базы или причина отсутствия достоверного значения.

## Источник и формат базы

Источник — открытые OSM-derived SQLite-базы проекта HvdWolf / SpeedAlert_Databases.

Схема, используемая приложением:

- speed_index.id
- speed_index.minLat, maxLat, minLon, maxLon
- speed_index.polyline
- speed_data.id
- speed_data.speed

Для ускорения сначала выполняется прямоугольный запрос SQL по координатам, затем геометрия сегмента проверяется по полилинии. Bounding box служит только предварительным фильтром и сам по себе не выбирает дорогу.

## Обновление и хранение

- База хранится в app-private filesDir/open-speed-databases.
- Архив загружается во временный файл, распаковывается, проверяется, затем устанавливается как {country}.sqlite.
- После первой загрузки lookup полностью локальный и не отправляет координаты в дорожный API.
- Проверка актуальности базы выполняется раз в 24 часа при активном GPS-отслеживании; загрузка проходит в фоновом потоке.
- При ошибке загрузки сохранённая рабочая база остаётся доступной.
- При отсутствии установленной базы и интернета приложение не может получить лимит и отображает ошибку.

## Map matching

- SQL bounding box отбирает дороги в радиусе, соответствующем точности GPS.
- Каждая полилиния проверяется точной проекцией GPS-точки на сегменты дороги.
- Сравниваются расстояния до нескольких кандидатов.
- Если два ближайших кандидата имеют разные скорости и разница в score меньше порога неоднозначности, лимит не отображается.
- Геометрия и расстояние остаются основными критериями выбора; неуверенный результат не показывается.

## Приватность

- Координаты не отправляются в Overpass, 2ГИС, HERE или другой дорожный lookup API.
- Для выбора страны используется Android Geocoder; поведение сетевого геокодера зависит от прошивки и сервисов устройства.
- История поездок не записывается и собственный backend приложения не используется.

## Ограничения

- База отражает только данные, имеющиеся в OpenStreetMap на дату её формирования.
- Если у дороги нет maxspeed, приложение не рассчитывает ограничение по предположительным правилам.
- Базы доступны не для всех стран и могут обновляться с задержкой.
- Геометрия дороги и точность GPS должны позволять однозначно выбрать текущий сегмент.
- Приложение не заменяет дорожные знаки и ПДД.
